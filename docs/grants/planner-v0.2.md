# Планировщик Rooms v0.2

Версия `0.2.0` расширяет проверенный алгоритм v0.1 тремя коммерческими ограничениями.

## Обязательные характеристики

Запрос может передать `requiredFeatures`. Набор помещений допускается к ранжированию, только если объединение его характеристик содержит все обязательные значения. Отказ фиксируется кодом `REQUIRED_FEATURES`.

## Дополнительные услуги

Запрос может передать `requestedServiceIds`. Цена выбранных услуг берётся только из серверного каталога и прибавляется к стоимости помещений один раз. Отсутствующая услуга отклоняет вариант с кодом `SERVICE_UNAVAILABLE`.

## Тарифы по времени

Для помещения хранится базовая цена и набор правил: название, дни недели, начало, окончание и цена за час. Правило может продолжаться после полуночи. Если бронь пересекает несколько тарифных интервалов, стоимость считается пропорционально каждой минуте. При пересечении правил применяется правило с большим приоритетом.

Клиент не передаёт цены в публичный API. Планировщик загружает комнаты, услуги и тарифы из каталога, поэтому итог нельзя занизить изменением запроса в браузере.

## Каталожная выдача

Параметр `maxVariantsPerRoomSet` позволяет получить только лучшее время для каждого набора помещений. Каталог использует значение `1`, поэтому более дешёвое помещение не вытесняет остальные площадки множеством соседних временных вариантов.

## Воспроизводимость

Хэш набора ограничений теперь включает обязательные характеристики, выбранные услуги, серверные цены услуг и тарифные правила. Одинаковые входные данные по-прежнему дают одинаковый порядок вариантов и одинаковый SHA-256.
